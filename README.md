# Journal

Journal intime web pour `journal.rivierenathan.fr`.

## Structure

- `api/` : backend et future logique d'authentification
- `web/` : interface React + TypeScript + Tailwind CSS

## Acces

L'application est pensee pour etre protegee par un mot de passe unique, sur le meme principe que le site `movies`.
Le mot de passe ne doit pas etre versionne en clair dans le code source.

## Demarrage

1. Installer les dependances du frontend dans `web/`.
2. Lancer le mode developpement Vite.
3. Brancher ensuite l'authentification et l'API.
